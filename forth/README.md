# Forth — partie ouverte d'Epona

Ce dossier contient tout le code qui peut être modifié sans recompiler le noyau Rust.

- `std/` — bibliothèque standard (framework drivers, utilitaires)
- `drivers/` — drivers matériels écrits en Forth
- `apps/` — applications
- `gui/` — thèmes et widgets
- `config/` — configuration (DRVMAP.FTH, default.fth)
- `boot/` — scripts de démarrage
