Epona OS

Système d’exploitation Rust UEFI — Bare-Metal, Forth VM, JIT x86-64, Forth.

Présentation

Epona OS est un système d’exploitation français, libre et souverain, développé en Bretagne. Il combine un noyau Rust bare-metal sécurisé avec une machine virtuelle Forth ouverte, un compilateur JIT x86‑64 natif, un environnement shell, et plus de 700 primitives natives.

Conçu pour les développeurs bas‑niveau, les makers, les hackers hardware et les passionnés d’architecture, Epona OS offre un contrôle total du matériel : PCI, USB XHCI, NVMe, SATA, GPU, MMIO, ports I/O, etc.

Fonctionnalités principales

  • Noyau Rust 64‑bit autonome (ExitBootServices)
  • Machine virtuelle Forth + compilateur JIT x86‑64 natif
  • 700+ primitives Forth natives
  • Accès matériel direct : PCI, USB 3.0 XHCI, NVMe, SATA AHCI, GPU
  • Shell hybride avec 70 commandes natives

Roadmap 2028–2035

  • Scheduler CPU préemptif V2
  • VFS arborescent DevFS / ProcFS / RamFS / NVMe FAT32
  • Agent IA autonome de détection matérielle
  • Pile Bluetooth HCI + Wi‑Fi 802.11 + Audio HDA
  • Store souverain Forth signé

Installation USB Live

Copiez BOOTX64.EFI dans EFI/BOOT/ sur une clé USB FAT32, ajoutez BOOT.FTH et les dossiers forth/, drivers/, demos/, puis démarrez en UEFI.
