# Référence des Primitives Forth — Epona OS 1.98

Ce document est la référence API pour écrire des scripts et programmes Forth (`.fth`) sur Epona OS 1.98. L'OS utilise une VM Forth 64 bits (1 cellule = 8 octets) avec un dictionnaire dynamique, un compilateur JIT, et un accès bas-niveau direct au matériel.

## Conventions de la VM

- **Pile de données (Data Stack)** : Contient des entiers 64 bits signés (`i64`). Flag vrai = `-1`, faux = `0`.
- **Mémoire Logique (`memory`)** : 65536 cellules. `HERE` pointe sur le prochain espace libre. Les adresses `< 65536` ciblent cette mémoire.
- **Mémoire Octets (`byte_mem`)** : 256 Ko de RAM séparée pour les buffers DMA/Réseau/Polices.
- **Adressage Hybride** : Si une primitive d'accès mémoire (`c@`, `w@`, `l@`, `cmove`) reçoit une adresse `>= 65536`, elle bascule automatiquement en accès MMIO/Physique natif (pointeurs C bruts).
- **Flottants (FPU)** : Les `f64` sont stockés sur la pile de données sous forme de bits (`i64`). Les littéraux comme `3.14` sont automatiquement convertis.
- **Chaînes de caractères** : Standard Forth `( addr len )`. La mémoire logique stocke 1 octet par cellule (l'octet est masqué `& 0xFF`).

## 1. Structure du Langage et Compilation

### Définitions de mots
```forth
: nom-du-mot <corps> ;
:noname <corps> ; \ Mot anonyme, pousse son XT sur la pile
```

### Variables, Constantes, Valeurs
```forth
variable monvar        \ Alloue 1 cellule à HERE, crée le mot qui pousse son adresse
42 constant reponse    \ Crée un mot qui pousse 42
99 value compteur      \ Crée un mot qui pousse 99, modifiable à l'exécution
10 to compteur         \ Modifie la valeur de 'compteur'
```

### Structures de contrôle (Compilation)
```forth
if <corps> else <corps> then
begin <corps> until
begin <corps> flag while <corps> repeat
limit index do <corps> loop
limit index do <corps> inc +loop
case expr of <corps> endof expr2 of <corps> endof <défaut> endcase
```

### Variables Locales `{ }`
```forth
: test { a b -- c } a b + ;
: test2 { a b -- c ; c1 } 0 to c1 a b + to c1 c1 . ;
```

### Exceptions
```forth
\ Mode interprété
' monmot catch \ Exécute monmot. Renvoie 0 si OK, ou le code erreur

\ Mode structuré (compilation)
try <corps> catch <gestion erreur> endtry

42 throw      \ Lève l'exception 42
-1 abort"     \ Lève exception -2 et affiche le message si flag != 0
abort         \ Vide les piles et retourne au prompt
quit          \ Vide la pile de retour, retourne au prompt (garde la data stack)
```

### Chaînes de caractères
```forth
s" Bonjour"       \ ( addr len ) Chaîne littérale (sans échappements)
s\" Tab\tSaut\n"  \ ( addr len ) Chaîne avec échappements C-like
." Texte"         \ Affiche la chaîne à l'exécution
,\" MaChaine"     \ Compile une chaîne comptée dans le dictionnaire
```

### Inclusion de fichiers
```forth
include monfichier.fth
require deps.fth   \ Ne charge qu'une seule fois
```

## 12. Démarrage et Initialisation Système

Le système est initialisé par des appels explicites depuis Forth (généralement dans `BOOT.FTH`).

```forth
exit-uefi       \ Quitte les services UEFI, passe en mode runtime (IDT native)
init-gop        \ Affiche infos vidéo UEFI GOP
init-acpi       \ Parse tables ACPI et SMBIOS
init-pit        \ Démarre le PIT à 100Hz et active la préemption
init-usb        \ Initialise xHCI et détecte clavier
init-drivers    \ Charge tous les pilotes PCI enregistrés
```

```forth
;
```

# Epona OS 1.98 — Référence Complète (Basée sur le code source)

## Architecture de la Machine Virtuelle Forth

La VM Forth d'Epona OS est une implémentation 64 bits (1 cellule = 8 octets) avec un dictionnaire limité à 2048 mots et 65536 cellules de mémoire logique. Elle intègre un ordonnanceur préemptif, un compilateur JIT, et un gestionnaire de fenêtres complet.

### État interne de la VM (`ForthVm`)
- `stack` / `rstack` / `loop_rstack` : Piles de données, de retour, et de boucles (séparées pour éviter la corruption par les appels).
- `memory` : Mémoire logique Forth (65536 cellules i64).
- `byte_mem` : Mémoire u8 séparée de 256 Ko pour les DMA, réseau, et polices.
- `canvas` : Framebuffer logiciel Forth (dessin off-screen).
- `jit` : Moteur JIT (compile les mots à la volée, gère signatures et trampolines).
- `handler_stack` : Pile pour `catch`/`try` contenant `(stack_depth, rstack_depth, loop_depth, catch_ip)`.

### Instructions Compilées (`Op`)
Le compilateur transforme le code source en une suite d'`Op`.
- `Push(i64)`, `PushStr`, `PushStrAddr`, `Call(dict_idx)`, `CallPrim(idx)`, `Jump`, `JumpIfZero`.
- `Do`, `QDo`, `Leave`, `Loop`, `PlusLoop` (gèrent `loop_rstack`).
- `Try`, `Catch`, `EndTry`, `Throw`, `AbortQuote` (sémantique exception Forth 2012).
- `LocalGet/Set`, `LocalsAlloc/Free` (variables locales `{ }` avec base de pile).
- `SysLoad`, `SysRead`, `SysWrite` (VFS intégré au compilateur).
