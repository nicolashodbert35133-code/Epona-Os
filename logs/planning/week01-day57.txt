1) FORTH/STD/CORE.FTH (CREE)
-----------------------------
Bibliotheque PURE : aucun acces materiel (ni MMIO 23/24, ni PCI, ni IRQ,
ni framebuffer, ni fichiers). Une app distante peut s'appuyer dessus sans
connaitre le moindre detail x86_64.

Math (8) :
  clamp    ( n lo hi -- n' )
  between? ( n lo hi -- flag )   -1 si lo <= n <= hi
  even?    ( n -- flag )
  odd?     ( n -- flag )
  sgn      ( n -- -1|0|1 )
  gcd      ( a b -- g )          Euclide
  lcm      ( a b -- l )
  pow      ( base exp -- r )     exp >= 0

Chaines (7) : paires ( addr len ), un octet par cellule
  starts-with / ends-with ( a1 l1 a2 l2 -- flag )
  str-find  ( a1 l1 a2 l2 -- idx|-1 )
  count-char ( addr len ch -- n )
  upper / lower ( addr len -- ) en place
  trim      ( addr len -- addr' len' )

Nombres (2) :
  str>num   ( addr len -- n ok )  decimal signe, ok=-1/0
  num>str   ( n -- addr len )     buffer statique NUM-BUF (32 cells)

Conventions respectees : memoire UNIQUEMENT create (espace here), jamais
variable ; pas de exit dans un mot a locals ; locaux assignes depuis le
bas de la pile (ordres verifies dans LocalsAlloc, interpreter.rs l.11161).
