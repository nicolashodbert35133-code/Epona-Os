2) CONTRAT
   - u> ( u1 u2 -- flag ) : comparaison NON SIGNEE (u64), flag -1/0.
     Ex : 0 -1 u> -> 0 (0 < 2^64-1) ; -1 0 u> -> -1 (2^64-1 > 0) ;
     contraste avec > signe : -1 0 > -> -1, -1 0 u> -> -1.
   - within ( n lo hi -- flag ) : -1 si lo <= n < hi, sinon 0
     (comparaisons signees, borne HAUTE exclue, borne basse incluse).
   - pad ( -- addr ) : adresse d'une zone transitoire d'au moins /PAD
     cellules, sous la zone WORD.

3) MECANIQUE (src/interpreter.rs)
   - Primitive 1832 = u> : pop b puis a, push (a as u64) > (b as u64) ? -1 : 0.

   - PAD n'est PAS une primitive : nouvel opcode Op::Pad (ajoute a l'enum
