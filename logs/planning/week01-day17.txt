FICHE D'ANALYSE - FIND ( c-addr -- c-addr 0 | xt 1 | xt -1 )
-----------------------------------------------------------

1) ETAT ACTUEL (code, interpreter.rs l.2254-2278)
   Signature effective : ( addr len -- idx | -1 )
     - pop len, pop addr
     - si addr>=0 et 0<len<=256 : lit len octets de memory[addr] (1 octet
       par cellule via & 0xFF), from_utf8, lookup_word(name)
     - trouve : push dict_idx ; introuvable : push -1
   NON CONFORME sur 3 points :
     a) la signature attend un couple (addr len) au lieu d'une chaine
        comptee ;
     b) elle ne restitue pas c-addr ;
     c) elle ne distingue pas immediat/non-immediat (flag 1/-1).

2) FORMAT DE CHAINE ACTUEL DANS EPONA
   - Tokenizer : tokens &str separes par des espaces (PAS de chaines
     comptees pour l'interpretation).
   - s" / ." / ," : texte -> string_pool, puis recopie dans
     memory[HERE..] (1 octet par cellule i64) a l'execution -> (addr len).
     Ce format (addr len) est utilise par `type` (119) et par l'actuel find.
   - Noms de mots : dictionary[].name = [u8; 64] NUL-terminé, compares par
     word_name_eq (insensible a la casse), stockes via encode_name.
   - lookup_word(name: &str) : parcourt search_order (du plus prioritaire au
     moins), dernier mot de chaque vocabulaire (shadowing). -> Option<usize>
     (index dans dictionary[]).
   - Il n'existe PAS de format de chaine comptee standard (pas de WORD, pas
     de C" normalise) : la chaine comptee devra etre construite a la main
     dans memory[] (ex. 1 octet/cellule : longueur puis octets du nom).

3) CONTRAT STANDARD FORTH 2012
   FIND ( c-addr -- c-addr 0 | xt 1 | xt -1 )
     - c-addr pointe une CHAINE COMPTEE : l'octet a c-addr est la longueur,
       les c-addr+1 .. c-addr+n sont le nom.
     - absente       -> c-addr 0     (c-addr restitue, pas trouve)
     - trouve, non immediat -> xt 1
     - trouve, immediat    -> xt -1
   Dans le cas trouve, c-addr est CONSOMME (remplace par xt) : la notation
   `-- xt 1` ne contient pas c-addr.
   xt Epona = index dans dictionary[] (meme convention que execute (102),
   ' , ['], literal) : coherent, reutilisable tel quel.

4) CONCEPTION PREVUE (Jour 18)
   Reecrire la primitive 103 sans toucher a lookup_word / tokenizer :
     - pop c-addr ;
     - len = (memory[c-addr] & 0xFF) ; nom = len octets depuis
       memory[c-addr+1 ..] (1 octet/cellule) ;
     - from_utf8 -> lookup_word ;
     - None  -> push c-addr ; push 0 ;
     - Some(i) -> push i ; push (si dictionary[i].immediate alors -1
       sinon 1) ;
     - bornes : len 1..=63, verifier c-addr+1+len <= memory.len() sinon
       traiter comme introuvable (c-addr 0).
   Aucun autre mot ne depend de l'ancienne signature (grep BOOT.FTH et
   drivers : aucune utilisation de la primitive `find` ; les `find-device`
   / `drvmap:find` / `pci:find-vendor` sont des definitions Forth locales).
   Le mot `execute` (102) utilise deja dictionary[idx] : compatible.
