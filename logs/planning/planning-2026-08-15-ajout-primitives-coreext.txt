de la famille 2R-ops), DEFER/IS/ACTION-OF presents mais DEFER@/DEFER! absents

SUITE (meme seance) : IMPLEMENTATION J59-J62 + FICHIERS DE TEST
----------------------------------------------------------------
- J59 (SAVE-INPUT/RESTORE-INPUT) :
    * champ ForthVm.input_snapshots: Vec<(String, usize, i64)> (source_buffer,
      source_addr, >in) ; capacite 32.
    * primitives 1837 save-input ( -- flag ) : -1 si snapshot pousse, 0 si
      pile saturee (>= 32).
    * primitives 1838 restore-input ( flag -- ) : restaure la spec, -1 si ok,
      0 si flag 0 ou pile vide.
    * add_primitive("save-input", 1837), add_primitive("restore-input", 1838).
- J60 (SOURCE-ID/UNUSED) :
    * champ ForthVm.source_id: i64 = 0 (terminal) ; eval_source le passe a -1
      pendant une chaine evaluate et le restaure a la fin.
    * primitive 1839 source-id ( -- n ) : pousse self.source_id.
    * primitive 1840 unused ( -- u ) : MAX_MEM - here (relation here unused +
      = MAX_MEM).
- J61 (ROLL/2R@) :
    * primitive 1841 roll ( x_n ... x_0 n -- x_{n-1} ... x_0 x_n ) : remove
      a l'indice len-1-n puis push ; n >= len -> pile inchangee (condition
      ambigue standard).
    * primitive 1842 2r@ ( -- x1 x2 ) : copie les 2 cellules du sommet du
      return stack sans depiler.
- J62 ([COMPILE]) :
    * branche tokenizer mode compilation, cote postpone : compile la
      semantique du mot suivant meme immediat (Core Ext 6.2.0920).
- Fichiers de test crees (conventions NB-FAILS/verif) :

    * forth/core2012/jour61.fth  : roll (0/1/2 = noop/swap/rot, n>=len

    * forth/core2012/jour62.fth  : [compile] sur mot ordinaire + immediat +

SUITE 2 (meme seance) : J62b - C" / DEFER@ / DEFER!
------------------------------------------------------
Decision utilisateur : implementer C" + DEFER@/DEFER! (derniers Core Ext
manquants) au lieu de les laisser en priorite basse.

- C" (Core Ext 6.2.0765) : cas tokenizer ajoutes (MODE COMPILATION + MODE
  INTERPRETATION), identiques a s" : parse ccc<quote>, stocke la chaine EN
  DATA SPACE via here (interp : pousse addr+len ; compile : Op::PushStrAddr
  pour le runtime ( -- c-addr u )).
- DEFER@ (prim 1844) et DEFER! (prim 1845) : implementes dans exec_primitive
  apres 1842 (avant scheduler_v2) ; registres via add_primitive apres 2r@.
    * defer@ ( xt1 -- xt2 ) : cherche Op::CallDeferred(addr) dans les ops du
      mot xt1 (index dictionnaire), pousse memory[addr] (cellule du defer,
      -1 si non assigne). Non-defer -> -1.
    * defer! ( xt2 xt1 -- ) : meme detection, ecrit memory[addr] = xt2
      (equivalent de IS sur xt).
- Fichier de test cree : forth/core2012/jour62b.fth
    * c" interprete : longueur (7/10), premier octet ('b'=98, 'p'=112),
      multi-mots (espaces preserves), persistance (relisible apres coup).
    * c" compile : mots c62 (len 11, 'c'=99) et c62b (len 2, 'h'=104).
    * defer@ : xt assigne via is re-lisible et executable (111), defer non
      assigne -> -1.
    * defer! : change la cible (222), cycles d'affectation, profondeur
      inchangee.
- Builds : dev et release OK (0 erreur / 413 warnings baseline).
- qemu_img resynchronise : BOOTX64.EFI + forth/core2012/jour62b.fth.
