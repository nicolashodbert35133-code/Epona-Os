2) DOCUMENTATION (docs/DEV_GUIDE_DRIVER_AGENT.md §6.7)
-------------------------------------------------------
Table des 8 mots (pile + description), conventions :
- Chemins : separateur / (FAT32 resout sur /), relatif racine volume,
  insensible a la casse. Attention : le shell convertit / en \ ; dans les
  mots Forth, utiliser toujours /.
- Buffer PHYSIQUE obligatoire (le FS lit/ecrit des blocs via block_read) :
  mem:alloc-pages ( n -- vaddr ) -> mmio-b@ ( addr -- u8 ) pour relire
  octet par octet -> mem:free-pages ( vaddr n -- ). Le buffer here normal
  (espace Forth) n'est PAS un buffer physique.
- Erreurs : file-exists = 0 si absent OU vide (limite connue) ; file-size
  = 0 si absent, -1 si FS non monte ; file-read/read-file/file-write = -1
  si fichier absent ou FS non monte ; list-dir = -1 si FS non monte.
