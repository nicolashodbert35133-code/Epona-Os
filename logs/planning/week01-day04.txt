BUGS DECOUVERTS CE JOUR (en plus de l'audit)
-------------------------------------------
1. -rot (idx 38 dans group0 / exec_primitive) :
      code = remove(len-3) + push  -> c'est ROT, pas -rot.
      Norme -rot : ( a b c -- c a b ).  1 2 3 -rot = 3 1 2 (sommet 2).
      Actuel : 1 2 3 -rot = 2 3 1 (sommet 1).
      Fix a prevoir (Jour 8+) : remove(len-1) + insert(len-2).
2. tuck (idx 40) :
      code = a=stack[len-2] ; insert(len-2, a).
      Norme tuck : ( a b -- b a b ).  1 2 tuck = 2 1 2 (sommet 2).
      Actuel : 1 2 tuck = 2 1 1 (copie du bas au lieu de dupliquer x1).
      Fix : push(stack[len-1]) ; swap(len-2, len-1).
3. Rappels deja connus (audit) retrouves par les tests :
      = <> < > <= >= 0= 0<> 0< 0> renvoient 1 au lieu de -1 (idx 37/58..66).
      rshift (idx 72) : wrapping_shr sur i64 = arithmetique, norme = logique.
      2/ (idx 52) : v / 2 tronque vers zero, norme = decalage arithmetique.
